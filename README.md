# 🤖 JARVIS AI — Offline Voice Assistant (Python + Ollama)

Jarvis AI is a **fully offline, voice-controlled AI assistant** built using **Python**, **Speech Recognition**, and **Ollama**.  
It listens to your voice 🎤, understands your commands 🧠, and responds back with speech 🔊 — **without any API keys, internet, or usage limits**.

> 💡 Inspired by Iron Man’s Jarvis, built for students & developers.

---

## ✨ Features

- 🎙️ **Voice Input** (Speech Recognition)
- 🧠 **Offline AI Brain** (Ollama + LLaMA 3 / Mistral)
- 🔊 **Text-to-Speech Output** (macOS `say`)
- 🌐 Open websites (Google, YouTube, Wikipedia)
- ⏰ Tell current time
- 📁 Save AI responses to files
- ❌ No API keys
- 💸 Zero cost
- 🚀 Unlimited usage

---

## 🛠️ Tech Stack

- **Python 3**
- **SpeechRecognition**
- **Ollama**
- **LLaMA 3 / Mistral models**
- **macOS** and on any Operating System
